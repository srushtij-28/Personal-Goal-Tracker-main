# Personal Goal Tracker

A simple Python command-line application to set personal goals,
track progress, and manage goal completion.

## Features

- Add personal goals
- View all goals
- Search goals by title or description
- Update progress percentage
- Mark goals as completed
- Delete goals
- Display goal statistics
- Store data using JSON

## Technologies Used

- Python
- JSON
- File Handling
- Date and Time Handling
